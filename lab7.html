Тема та мета

Тема: Двовимірні масиви та обробка квадратних матриць.

Мета: Опанувати введення й обробку двовимірних масивів, роботу з головною діагоналлю, модифікацію матриці та обчислення оберненої матриці через визначник і алгебраїчні доповнення.

Умова завдань

Завдання 1

Створити квадратну матрицю розмірності n ≥ 3 з ручним або автоматичним заповненням. Знайти суму елементів головної діагоналі та елементів над нею, які більші за всі елементи під головною діагоналлю. Записати цю суму в додатковий рядок і стовпець, передбачивши контроль меж матриці.

Завдання 2

Створити квадратну матрицю A розмірності m ≥ 3. Передбачити введення з клавіатури або генерацію додатних та від’ємних псевдовипадкових чисел. Знайти обернену матрицю, використовуючи алгебраїчні доповнення. Вивести вхідну матрицю, визначник та результат; передбачити виведення проміжних обчислень.

Аналіз завдань

Завдання 1

Для елементів під головною діагоналлю виконується i > j. Спочатку серед них знаходиться максимум M. Після цього додаються лише ті елементи, для яких i ≤ j та aᵢⱼ > M. Строга нерівність застосовується і до елементів самої головної діагоналі.

Початковий розмір може становити від 3 до 10. Додатковий рядок і стовпець записуються за індексом n, тому розширення можливе лише для n ≤ 9. Якщо n = 10, сума обчислюється, але модифікація не виконується через обмеження масиву.

Завдання 2

Для кожного елемента створюється мінор шляхом вилучення відповідного рядка та стовпця. Його визначник із множником (−1)ⁱ⁺ʲ утворює алгебраїчне доповнення. Визначник матриці обчислюється рекурсивним розкладом за першим рядком, а для матриці 2 × 2 використовується безпосередня формула.

Обернена матриця існує за det(A) ≠ 0. Матриця алгебраїчних доповнень транспонується, після чого кожний її елемент ділиться на визначник: A⁻¹ = Cᵀ / det(A). У програмі розмір обмежено значеннями від 3 до 6.

/// <summary>
/// Функція для знаходження максимального елемента
/// під головною діагоналлю матриці
/// </summary>
void checkMaxElementUnderMainDiagonal()
{
	maxElementUnderMainDiagonal = squareMatrix[1][0];

	for (i = 0; i < n; ++i)
	{
		for (j = 0; j < n; ++j)
		{
			if (i > j
				&& squareMatrix[i][j] > maxElementUnderMainDiagonal)
			{
				maxElementUnderMainDiagonal = squareMatrix[i][j];
			}
		}
	}

	cout << "Максимальний елемент масиву під головною діагоналлю: "
		<< maxElementUnderMainDiagonal << endl;
}

/// <summary>
/// Функція для додавання елементів головної діагоналі
/// та елементів над нею до загальної суми
/// </summary>
void mainDiagonalAndAboveSum()
{
	if (i <= j && squareMatrix[i][j] > maxElementUnderMainDiagonal)
	{
		upperPartSum += squareMatrix[i][j];
	}
}

/// <summary>
/// Функція для обчислення суми елементів головної діагоналі

void matrixSumChecker()
{
	for (i = 0; i < n; ++i)
	{
		for (j = 0; j < n; ++j)
		{
			mainDiagonalAndAboveSum();
		}
	}

		<< "які більше ніж усі елементи під діагоналлю: "

/// Функція для формування та виведення модифікованої матриці
/// </summary>
void matrixModificationOutput()
{
	cout << "Модифікована матриця:" << endl;

	if (n + 1 > maxArraySize)
	{
		cout << "Вихід за межі матриці, модифікація неможлива"
			<< endl;
		return;
	}

	for (i = 0; i < n + 1; ++i)
	{
		for (j = 0; j < n + 1; ++j)
		{
			if (i == n || j == n)
			{
				squareMatrix[i][j] = upperPartSum;
			}

			cout << setw(4) << squareMatrix[i][j];
		}

		cout << endl;
	}
}

/// <summary>
/// Функція для створення мінорної матриці шляхом
/// видалення заданого рядка та стовпця
/// </summary>
/// <param name="squareMatrix">Початкова квадратна матриця</param>
/// <param name="minorMatrix">Матриця для збереження мінора</param>
/// <param name="size">Розмір початкової матриці</param>
/// <param name="deletedRow">Індекс рядка, який видаляється</param>
/// <param name="deletedColumn">Індекс стовпця, який видаляється</param>
void minorMatrixCreate(int squareMatrix[maxArraySize][maxArraySize], int minorMatrix[maxArraySize][maxArraySize],
	int size, int deletedRow, int deletedColumn)
{
	int minorI = 0;
	int minorJ = 0;
	for (int i = 0; i < size; i++)
	{
		for (int j = 0; j < size; j++)
		{
			if (i != deletedRow && j != deletedColumn)
			{
				minorMatrix[minorI][minorJ] = squareMatrix[i][j];
				minorJ++;
			}
		}

		if (i != deletedRow)
		{
			minorI++;
			minorJ = 0;
		}
	}
}

/// <summary>
/// Функція для рекурсивного обчислення визначника матриці
/// </summary>
/// <param name="matrix">Матриця для обчислення визначника</param>
/// <param name="size">Розмір матриці</param>
/// <returns>Значення визначника матриці</returns>
float findMatrixDeterminant(int matrix[maxArraySize][maxArraySize], int size)
{
	float determinant = 0;
	if (size == 2)
	{
		determinant = matrix[0][0] * matrix[1][1] - matrix[0][1] * matrix[1][0];
	}
	else
	{
		for (int column = 0; column < size; column++)
		{
			int sign = 1;
			int currentMinor[maxArraySize][maxArraySize];

			if (column % 2 != 0)
			{
				sign = -1;
			}

			minorMatrixCreate(matrix, currentMinor, size, 0, column);

			float minorDeterminant = findMatrixDeterminant(currentMinor, size - 1);

			determinant += sign * matrix[0][column] * minorDeterminant;
		}
	}

	return determinant;
}

/// <summary>
/// Функція для обчислення алгебраїчних доповнень
/// елементів матриці
/// </summary>
/// <param name="matrix">Початкова квадратна матриця</param>
/// <param name="algebraicComplementMatrix">
/// Матриця для збереження алгебраїчних доповнень
/// </param>
/// <param name="size">Розмір матриці</param>
void findAlgebraicComplements(int matrix[maxArraySize][maxArraySize], float algebraicComplementMatrix[maxArraySize][maxArraySize], int size)
{
	for (int i = 0; i < size; i++)
	{
		for (int j = 0; j < size; j++)
		{
			int sign = 1;
			int currentMinor[maxArraySize][maxArraySize];
			if ((i + j) % 2 != 0)
			{
				sign = -1;
			}
			minorMatrixCreate(matrix, currentMinor, size, i, j);

			float minorDeterminant = findMatrixDeterminant(currentMinor, size - 1);

			algebraicComplementMatrix[i][j] = sign * minorDeterminant;
		}
	}
}

/// <summary>
/// Функція для обчислення елементів оберненої матриці
/// </summary>
/// <param name="determinant">Визначник початкової матриці</param>
void findInverseMatrix(float determinant)
{
	for (int i = 0; i < m; ++i)
	{
		for (int j = 0; j < m; ++j)
		{
			inverseMatrix[i][j] = algebraicComplementMatrix[j][i] / determinant;
		}
	}
}

Перевірка результатів

Завдання 1

У наведеній матриці максимум під головною діагоналлю дорівнює 23. У головній діагоналі та над нею умову перевищення виконують значення 27, 26 і 28. Їх сума 81 збігається з перевіркою у WolframAlpha. Додатковий рядок та стовпець заповнено числом 81.

Завдання 2

Для матриці з рядками (−9, 9, −8), (3, 3, 0), (−7, 3, −6) визначник дорівнює 84. Рядки матриці алгебраїчних доповнень: (−18, 18, 30), (30, −2, −36), (24, −24, −54). Вони збігаються з результатом WolframAlpha.

Транспонування доповнень і ділення на 84 дає обернену матрицю, наведену в програмі та Excel. Незалежна перевірка множенням A · A⁻¹ дає одиничну матрицю; відмінності останніх десяткових знаків у виведенні пов’язані з округленням.

Висновки

У ході лабораторної роботи опрацьовано двовимірні масиви та способи обходу квадратних матриць. Закріплено відповідність між індексами рядків і стовпців та геометричним положенням елемента відносно головної діагоналі. Розподіл обчислень на функції дозволив окремо перевірити введення, пошук, модифікацію та виведення.

У першому завданні максимум нижньої частини матриці використано як межу для відбору елементів верхньої частини. Для контрольної матриці отримано максимум 23 і суму 81. Перевірка 27 + 26 + 28 підтвердила результат; додаткові рядок та стовпець сформовано без зміни початкових елементів.

Контроль меж масиву показав необхідність враховувати місце для розширення матриці. Для найбільшого дозволеного початкового розміру обчислення суми залишається можливим, а додавання рядка та стовпця відхиляється. Це закріпило розуміння відмінності між логічним розміром матриці та місткістю виділеного масиву.

У другому завданні побудовано мінори, рекурсивно обчислено визначник і сформовано матрицю алгебраїчних доповнень. На контрольному прикладі отримано визначник 84. Перевірки у WolframAlpha та Excel підтвердили доповнення й обернену матрицю, а транспонування стало необхідним кроком між цими двома результатами.

Робота поєднала програмну обробку матриць з алгоритмами лінійної алгебри. Закріплено перевірку існування оберненої матриці, правила знаків алгебраїчних доповнень і порівняння наближених результатів з точними дробами.
