Тема та мета

Тема: Одновимірні масиви. Сортування, пошук та векторна алгебра.

Мета: Навчитися створювати й обробляти одновимірні масиви, знаходити екстремальні елементи та їх індекси. Реалізувати бульбашкове сортування, лінійний пошук і розкладання вектора за трьома заданими векторами.

Умова завдань

Завдання 1

Створити одновимірний масив, кількість елементів якого вводиться з клавіатури. Передбачити ручне заповнення або генерацію псевдовипадкових чисел. Поміняти місцями максимальний і мінімальний елементи. Вивести їх значення та індекси, вхідний і вихідний масиви.

Завдання 2

Створити одновимірний масив із вибором способу заповнення. Відсортувати його методом бульбашкового сортування, виводячи проміжні результати проходів. Здійснити ітераційний лінійний пошук заданого числа.

Завдання 3

Увести координати вектора X = (x, y, z). Визначити його розкладання за векторами a = (a₁, a₂, a₃), b = (b₁, b₂, b₃), c = (c₁, c₂, c₃), координати яких задаються вручну або генеруються. Вивести коефіцієнти розкладання у вигляді скорочених дробів.

Аналіз завдань

Завдання 1

Мінімальне й максимальне значення спочатку дорівнюють першому елементу масиву. Під час послідовного обходу порівнюються інші елементи та запам’ятовуються індекси знайдених екстремумів. Після завершення пошуку обмін виконується через тимчасову змінну. Індексація починається з нуля; за повторення екстремального значення зберігається його перша позиція.

Розмір масиву обмежено значеннями від 1 до 20. Пошук екстремумів потребує одного обходу масиву, а обмін змінює лише дві знайдені позиції.

Завдання 2

Бульбашкове сортування порівнює сусідні елементи й обмінює їх, якщо попередній більший за наступний. Після кожного проходу виводиться поточний масив. Ознака changed визначає продовження: прохід без жодного обміну завершує сортування.

Лінійний пошук перевіряє елементи від початку масиву та зупиняється на першому збігу. Якщо жодного збігу немає, виводиться відповідне повідомлення. Індекс знайденого числа належить уже відсортованому масиву.

Завдання 3

Шукане розкладання має вигляд X = αa + βb + γc. Три координати утворюють систему лінійних рівнянь відносно α, β та γ. У програмі коефіцієнти знаходяться послідовним виключенням невідомих із подальшим обчисленням чисельників і знаменників.

Перед діленням перевіряються знаменники, які використовуються у вибраній схемі обчислення. Дроби скорочуються за найбільшим спільним дільником, а знак переноситься в чисельник. Результат перевіряється підстановкою отриманих коефіцієнтів у координати вектора X.

/// Функція для пошуку мінімального та максимального елементів масиву
/// та їх індексів
/// </summary>
void findMinMax()
{
	maxValue = minValue = arrayNumbers[0];
	maxIndex = minIndex = 0;

	for (int index = 1; index < arraySize; ++index)
	{
		if (arrayNumbers[index] < minValue)
		{
			minIndex = index;
			minValue = arrayNumbers[index];
		}

		if (arrayNumbers[index] > maxValue)
		{
			maxIndex = index;
			maxValue = arrayNumbers[index];
		}
	}
}

{
	int temporaryValue = arrayNumbers[minIndex]; // Тимчасове значення для обміну

	arrayNumbers[minIndex] = arrayNumbers[maxIndex];
	arrayNumbers[maxIndex] = temporaryValue;
}

/// <summary>
/// Функція для сортування масиву методом бульбашкового сортування
/// </summary>
void bubbleSort()
{
	int sortBuffer; // Тимчасове значення для обміну елементів масиву
	bool changed = false; // Ознака виконання обміну елементів масиву

	cout << "Сортування масиву..." << endl;

	do
	{
		changed = false;

		for (int index = 1; index < arraySize; ++index)
		{
			if (arrayNumbers[index - 1] > arrayNumbers[index])
			{
				sortBuffer = arrayNumbers[index - 1];
				arrayNumbers[index - 1] = arrayNumbers[index];
				arrayNumbers[index] = sortBuffer;
				changed = true;
			}
		}

		if (!changed)
		{
			cout << "Відсортований масив:" << endl;
		}

		outputArray();
		cout << endl;
	} while (changed);
}

/// <summary>
/// Функція для знаходження найбільшого спільного дільника
/// за алгоритмом Евкліда
/// </summary>
/// <param name="numerator">Чисельник дробу</param>
/// <param name="denominator">Знаменник дробу</param>
/// <returns>
/// Найбільший спільний дільник чисельника та знаменника
/// </returns>
int calculateGCD(int numerator, int denominator)
{
	if (numerator < 0)
	{
		numerator *= -1;
	}

	if (denominator < 0)
	{
		denominator *= -1;
	}

	if (numerator == 0)
	{
		return 1;
	}

	while (numerator != denominator)
	{
		if (numerator > denominator)
		{
			numerator -= denominator;
		}
		else
		{
			denominator -= numerator;
		}
	}

	return numerator;
}

/// <summary>
/// Функція для розкладання вектора X за векторами A, B та C
/// та виведення результату розкладання
/// </summary>
void decomposeVector()
{
	int numeratorX; // Чисельник коефіцієнта при векторі A
	int numeratorY; // Чисельник коефіцієнта при векторі B
	int numeratorZ; // Чисельник коефіцієнта при векторі C

	int denominatorX; // Знаменник коефіцієнта при векторі A
	int denominatorY; // Знаменник коефіцієнта при векторі B
	int denominatorZ; // Знаменник коефіцієнта при векторі C

	int coefficientA = vectorA[1] * vectorB[0] - vectorA[0] * vectorB[1];
	int coefficientB = vectorC[0] * vectorA[1] - vectorA[0] * vectorC[1];
	int coefficientC = vectorA[1] * vectorX[0] - vectorA[0] * vectorX[1];
	int coefficientD = vectorA[2] * vectorB[0] - vectorA[0] * vectorB[2];
	int coefficientE = vectorA[2] * vectorC[0] - vectorA[0] * vectorC[2];
	int coefficientF = vectorA[2] * vectorX[0] - vectorA[0] * vectorX[2];

	if (coefficientA * coefficientE - coefficientB * coefficientD == 0
		|| coefficientA == 0 || vectorA[0] == 0)
	{
		cout << "Відбувається ділення на нуль, рішення неможливе!" << endl;
		return;
	}

	numeratorZ = coefficientA * coefficientF - coefficientD * coefficientC;
	denominatorZ = coefficientA * coefficientE - coefficientB * coefficientD;

	numeratorY = coefficientC * denominatorZ - coefficientB * numeratorZ;
	denominatorY = coefficientA * denominatorZ;

	numeratorX = vectorX[0] * denominatorY - vectorB[0] * numeratorY
	- vectorC[0] * numeratorZ * coefficientA;
	denominatorX = vectorA[0] * denominatorY;

	int divisorX = calculateGCD(numeratorX, denominatorX); // НСД коефіцієнта A
	int divisorY = calculateGCD(numeratorY, denominatorY); // НСД коефіцієнта B
	int divisorZ = calculateGCD(numeratorZ, denominatorZ); // НСД коефіцієнта C

	numeratorX /= divisorX;
	denominatorX /= divisorX;

	numeratorY /= divisorY;
	denominatorY /= divisorY;

	numeratorZ /= divisorZ;
	denominatorZ /= divisorZ;

	if (denominatorX < 0)
	{
		numeratorX *= -1;
		denominatorX *= -1;
	}

	if (denominatorY < 0)
	{
		numeratorY *= -1;
		denominatorY *= -1;
	}

	if (denominatorZ < 0)
	{
		numeratorZ *= -1;
		denominatorZ *= -1;
	}

	cout << "Розкладання вектора X: X = "
		<< numeratorX << "/" << denominatorX << " * a + "
		<< numeratorY << "/" << denominatorY << " * b + "
		<< numeratorZ << "/" << denominatorZ << " * c"
		<< endl;
}

	identificationOutput();
	fillVectorManually(vectorX, 'X');

Завдання 1

Для ручного масиву 8, 2, 9, 7, 2, 15, 8, 21, 9, 1 максимум дорівнює 21 з індексом 7, мінімум — 1 з індексом 9. Після обміну отримано 8, 2, 9, 7, 2, 15, 8, 1, 9, 21.

Завдання 2

Для ручного масиву 30, 13, 23, 27, 1, 8, 9, 28, 23, 17 після сортування отримано 1, 8, 9, 13, 17, 23, 23, 27, 28, 30. Число 27 має індекс 7, що відповідає виведенню програми.

Завдання 3

Для X = (−4, 4, 4), a = (3, 1, 0), b = (−1, 0, 6), c = (−1, 2, 0) отримано α = −8/21, β = 2/3, γ = 46/21. Підстановка дає координати (−4, 4, 4), що підтверджує розкладання.

Висновки

У лабораторній роботі закріплено створення та обробку одновимірних масивів. Для кожного завдання реалізовано окремі функції введення, обчислення та виведення, що дозволило послідовно простежити перетворення даних. Ручне заповнення використано для перевірки конкретних прикладів, а автоматичне — для роботи з різними наборами значень.

У першому завданні знайдено мінімальний і максимальний елементи та виконано їх обмін. Перевірка індексів показала, що нумерація елементів починається з нуля. У ручному тесті значення 21 та 1 перемістилися між позиціями 7 і 9, а решта елементів зберегли свої місця.

У другому завданні реалізовано бульбашкове сортування та ітераційний лінійний пошук. Проміжні проходи показали поступове впорядкування масиву. Завершення сортування за відсутністю обмінів дозволяє не виконувати зайві проходи вже впорядкованого набору; пошук повертає першу позицію заданого числа.

У третьому завданні використано масиви для збереження координат векторів і розв’язано систему рівнянь для коефіцієнтів розкладання. Скорочення дробів та приведення знаменників до додатного знака зробили результат зручним для підстановки. Контрольний приклад підтвердив відновлення всіх трьох координат початкового вектора.
