Тема та мета

Тема: Структури та масиви структур.

Мета: Навчитися описувати пов’язані дані структурою, створювати масив записів, виконувати пошук і вилучення за умовою, накопичувати статистику та виводити дані у табличній формі.

Умова завдання

Завдання 1

Створити масив структур із полями: факультет, курс, група, прізвище студента та екзаменаційні оцінки. Передбачити ручне або автоматичне заповнення. Знайти й вилучити студентів факультету ФІТ, які мають дві та більше двійок за сесію; визначити факультет із найбільшою кількістю відмінників першого курсу та курс, з якого вилучено найбільше студентів. Організувати меню запитів і виведення таблиць.

Аналіз завдань

Завдання 1

Структура studentData об’єднує символьні поля факультету, групи й прізвища, номер курсу та масив із шести оцінок. Масив містить до 40 студентів. Ручне введення перевіряє факультет, курс і діапазон оцінок; автоматичне формує записи з визначених наборів значень.

Під час вилучення порівнюється факультет і підраховуються оцінки «2». Запис із двома або більше такими оцінками видаляється зсувом наступних структур вліво. Кількість студентів зменшується, а індекс коригується, щоб перевірити запис, який зайняв звільнену позицію. До зсуву збільшується лічильник вилучень відповідного курсу.

Відмінником першого курсу вважається студент, для якого course == 1 і всі шість оцінок дорівнюють 5. Кількість таких студентів підраховується за факультетами. Окремий масив зберігає кількість вилучених за курсами; найбільше значення визначає результат третього запиту. За однакових максимумів у наведеному коді залишається перший із них.

const int maxStudentNumber = 40; // Максимальна кількість студентів

// Масив назв факультетів
const char faculties[][10] =

	"ФІТ",
	"ФКНК",

/// <summary>
/// Структура для збереження інформації про студента
/// </summary>
struct studentData
{
	char faculty[15]; // Назва факультету
	int course; // Номер курсу
	char group[10]; // Назва групи
	char surname[15]; // Прізвище студента
	int grade[maxGradeNumber]; // Масив оцінок студента
};

/// <summary>
/// Функція для ручного введення даних студентів
/// </summary>
/// <param name="students">Масив даних студентів</param>
/// <param name="studentCount">Кількість студентів</param>
void inputStudentsData(studentData students[], int& studentCount)
{
	do
	{
		cout << "Введіть кількість студентів: ";
		cin >> studentCount;
	} while (studentCount < 1 || studentCount > maxStudentNumber);

	for (int i = 0; i < studentCount; i++)
	{
		do
		{
			cout << "Введіть факультет студента (ФІТ, ФКНК, ФРЕКС): ";
			cin >> setw(15) >> students[i].faculty;
		} while (strcmp(students[i].faculty, "ФІТ") != 0
			&& strcmp(students[i].faculty, "ФКНК") != 0
			&& strcmp(students[i].faculty, "ФРЕКС") != 0);

		do
		{
			cout << "Введіть курс студента (від 1 до 4): ";
			cin >> students[i].course;
		} while (students[i].course < 1 || students[i].course > 4);

		cout << "Введіть групу студента: ";
		cin >> students[i].group;

		cout << "Введіть прізвище студента: ";
		cin >> students[i].surname;

		cout << "Введіть оцінки студента (від 2 до 5): ";

		for (int j = 0; j < maxGradeNumber; j++)
		{
			do
			{
				cin >> students[i].grade[j];
			} while (students[i].grade[j] < 2
				|| students[i].grade[j] > 5);
		}
	}
}

/// <summary>
/// Функція для автоматичного заповнення даних студентів
/// випадковими значеннями
/// </summary>
/// <param name="students">Масив даних студентів</param>
/// <param name="studentCount">Кількість студентів</param>
void automaticStudentsDataInput(studentData students[], int& studentCount)
{
	do
	{
		cout << "Введіть кількість студентів: ";
		cin >> studentCount;
	} while (studentCount < 1 || studentCount > maxStudentNumber);

	for (int i = 0; i < studentCount; i++)
	{
		int randomFaculty = rand() % 3; // Випадковий індекс факультету

		strcpy(students[i].faculty, faculties[randomFaculty]);
		students[i].course = rand() % 4 + 1;

		int randomGroup = rand() % 2; // Випадковий індекс групи

		if (randomFaculty == 0)
		{
			strcpy(students[i].group, fitGroups[randomGroup]);
		}
		else if (randomFaculty == 1)
		{
			strcpy(students[i].group, fknkGroups[randomGroup]);
		}
		else
		{
			strcpy(students[i].group, freksGroups[randomGroup]);
		}

		strcat(students[i].group, "-");

		// Перетворення номера курсу на символьний рядок
		char courseBuffer[2];
		courseBuffer[0] = students[i].course + '0';
		courseBuffer[1] = '\0';

		strcat(students[i].group, courseBuffer);

		// Формування випадкового номера групи
		char groupNumberBuffer[2];
		groupNumberBuffer[0] = rand() % 4 + 1 + '0';
		groupNumberBuffer[1] = '\0';

		strcat(students[i].group, groupNumberBuffer);

		int randomSurname = rand() % 11; // Випадковий індекс прізвища
		strcpy(students[i].surname, surnames[randomSurname]);

		// Ознака генерації студента-відмінника першого курсу
		bool topStudent = students[i].course == 1 && rand() % 5 == 0;

		for (int j = 0; j < maxGradeNumber; j++)
		{
			if (topStudent)
			{
				students[i].grade[j] = 5;
			}
			else
			{
				students[i].grade[j] = rand() % 4 + 2;
			}
		}
	}
}

/// <summary>
/// Функція для пошуку та видалення студентів заданого факультету,
/// які мають дві або більше незадовільних оцінок
/// </summary>
/// <param name="students">Масив даних студентів</param>
/// <param name="studentCount">Кількість студентів</param>
/// <param name="numberOfDeletedStudentsOnCourses">
/// Масив кількості видалених студентів за курсами
/// </param>
void deleteBadGradeStudents(studentData students[], int& studentCount,
	int numberOfDeletedStudentsOnCourses[])
{
	char facultyToFind[10]; // Назва факультету для пошуку
	bool studentsDeleted = false; // Ознака видалення студентів

	cout << "Введіть факультет для пошуку: ";
	cin >> setw(10) >> facultyToFind;

	cout << "Студенти " << facultyToFind
		<< ", які мають 2 або більше двійок за сесію: " << endl;

	for (int i = 0; i < studentCount; i++)
	{
		int badGrades = 0; // Кількість незадовільних оцінок
		bool deleteStudent = false; // Ознака необхідності видалення

		if (strcmp(students[i].faculty, facultyToFind) == 0)
		{
			for (int j = 0; j < maxGradeNumber; j++)
			{
				if (students[i].grade[j] == 2)
				{
					badGrades++;
				}

				if (badGrades >= 2)
				{
					numberOfDeletedStudentsOnCourses[students[i].course - 1]++;
					deleteStudent = true;
					break;
				}
			}
		}

		if (deleteStudent)
		{
			studentsDeleted = true;
			cout << students[i].surname << endl;

			// Зсув елементів масиву після видалення студента
			for (int j = i; j < studentCount - 1; j++)
			{
				students[j] = students[j + 1];
			}

			i--;
			studentCount--;
		}
	}

	if (!studentsDeleted)
	{
		cout << "Студентів із двома або більше двійками не знайдено."
			<< endl;
	}
}

/// <summary>
/// Функція для визначення кількості студентів-відмінників
/// першого курсу на кожному факультеті
/// </summary>
/// <param name="students">Масив даних студентів</param>
/// <param name="studentCount">Кількість студентів</param>
/// <param name="numberOfTopStudentsOnFaculties">
/// Масив кількості відмінників за факультетами
/// </param>
void findTopStudents(studentData students[], int studentCount,
	int numberOfTopStudentsOnFaculties[])
{
	for (int i = 0; i < 3; i++)
	{
		numberOfTopStudentsOnFaculties[i] = 0;
	}

	for (int i = 0; i < studentCount; i++)
	{
		int topGrades = 0; // Кількість оцінок «5» у студента

		if (students[i].course == 1)
		{
			for (int j = 0; j < maxGradeNumber; j++)
			{
				if (students[i].grade[j] == 5)
				{
					topGrades++;
				}
			}

			if (topGrades == maxGradeNumber)
			{
				if (strcmp(students[i].faculty, "ФІТ") == 0)
				{
					numberOfTopStudentsOnFaculties[0]++;
				}
				else if (strcmp(students[i].faculty, "ФКНК") == 0)
				{
					numberOfTopStudentsOnFaculties[1]++;
				}
				else if (strcmp(students[i].faculty, "ФРЕКС") == 0)
				{
					numberOfTopStudentsOnFaculties[2]++;
				}
			}
		}
	}
}

/// <summary>
/// Функція для визначення факультету з найбільшою
/// кількістю студентів-відмінників першого курсу
/// </summary>
/// <param name="numberOfTopStudentsOnFaculties">
/// Масив кількості відмінників за факультетами
/// </param>
void findFacultyWithMostTopStudents(int numberOfTopStudentsOnFaculties[])
{
	int maxIndex = 0; // Індекс факультету з найбільшою кількістю відмінників

	for (int i = 1; i < 3; i++)
	{
		if (numberOfTopStudentsOnFaculties[i] >
			numberOfTopStudentsOnFaculties[maxIndex])
		{
			maxIndex = i;
		}
	}

	if (numberOfTopStudentsOnFaculties[maxIndex] == 0)
	{
		cout << "На першому курсі немає відмінників." << endl;
		return;
	}

	cout << "Найбільше відмінників першого курсу на факультеті "
		<< faculties[maxIndex] << ": "
		<< numberOfTopStudentsOnFaculties[maxIndex] << endl;
}

/// <summary>
/// Функція для визначення курсу, з якого було
/// виключено найбільшу кількість студентів
/// </summary>
/// <param name="numberOfDeletedStudentsOnCourses">
/// Масив кількості видалених студентів за курсами
/// </param>
void findCourseWithMostDeletedStudents(int numberOfDeletedStudentsOnCourses[])
{
	int maxIndex = 0; // Індекс курсу з найбільшою кількістю виключених

	for (int i = 1; i < 4; i++)
	{
		if (numberOfDeletedStudentsOnCourses[i] >
			numberOfDeletedStudentsOnCourses[maxIndex])
		{
			maxIndex = i;
		}
	}

	if (numberOfDeletedStudentsOnCourses[maxIndex] == 0)
	{
		cout << "Виключених студентів немає" << endl;
		return;
	}

	cout << "Найбільше студентів було виключено з "
		<< maxIndex + 1 << " курсу: "
		<< numberOfDeletedStudentsOnCourses[maxIndex] << endl;
}

/// <summary>
/// Головна функція програми для керування введенням,
/// обробкою та аналізом даних студентів
/// </summary>
/// <returns>Код завершення програми</returns>
int main()
{
	identificationOutput();
	srand((unsigned)time(NULL));

	int studentCount = 0; // Поточна кількість студентів
	int numberOfDeletedStudentsOnCourses[4] = { 0 }; // Виключені за курсами
	int numberOfTopStudentsOnFaculties[3] = { 0 }; // Відмінники за факультетами
	studentData students[maxStudentNumber]; // Масив даних студентів
	int choice = 1; // Обраний пункт меню
	int inputChoice = 0; // Спосіб заповнення даних
	bool dataCreated = false; // Ознака створення даних студентів

	while (choice != 0)
	{
		cout << "1. Внести дані студентів" << endl
			<< "2. Вивести прізвища студентів факультету, які мають дві та більше"
			<< " двійки за сесію та вилучити їх" << endl
			<< "3. Визначити факультет, який на першому курсі має найбільшу кількість відмінників"
			<< endl
			<< "4. Визначити курс, на якому виключено найбільшу кількість студентів"
			<< endl
			<< "0. Вихід" << endl;

		cout << "Оберіть пункт меню: ";
		cin >> choice;

		switch (choice)
		{
		case 1:
			for (int i = 0; i < 4; i++)
			{
				numberOfDeletedStudentsOnCourses[i] = 0;
			}

			do
			{
				cout << "Виберіть спосіб заповнення даних "
					<< "(1 - вручну, 2 - автоматично): ";
				cin >> inputChoice;
			} while (inputChoice != 1 && inputChoice != 2);

			if (inputChoice == 1)
			{
				inputStudentsData(students, studentCount);
			}
			else
			{
				automaticStudentsDataInput(students, studentCount);
			}

			dataCreated = true;

			cout << "Початкова таблиця: " << endl;
			studentsDataTableOutput(students, studentCount);
			break;

		case 2:
			if (studentCount == 0)
			{
				cout << "У масиві немає даних студентів!" << endl;
				break;
			}

			deleteBadGradeStudents(
				students,
				studentCount,
				numberOfDeletedStudentsOnCourses);

			cout << "Таблиця після видалення двієчників: " << endl;
			studentsDataTableOutput(students, studentCount);
			break;

		case 3:
			if (!dataCreated)
			{
				cout << "Спочатку необхідно внести дані студентів!" << endl;
				break;
			}

			findTopStudents(
				students,
				studentCount,
				numberOfTopStudentsOnFaculties);

			findFacultyWithMostTopStudents(numberOfTopStudentsOnFaculties);
			break;

		case 4:
			if (!dataCreated)
			{
				cout << "Спочатку необхідно внести дані студентів!" << endl;
				break;
			}

			findCourseWithMostDeletedStudents(numberOfDeletedStudentsOnCourses);
			break;

		case 0:
			break;

		default:
			cout << "Такого пункту меню не існує!" << endl;
			break;
		}

		cout << endl;
	}
}

Перевірка результатів

Завдання 1

У початковій таблиці наведено 25 студентів. Для ФІТ вилучено шість записів: Ткаченко, Костенко, Баранов, Ткаченко, Петров, Коваленко. Кожен із цих записів має щонайменше дві оцінки «2», а після вилучення в таблиці залишилося 19 студентів.

Ручний підрахунок вилучень за курсами дає: 1-й — 2, 2-й — 1, 3-й — 1, 4-й — 2. За рівних максимумів програма обирає перший курс; виведений результат — 1-й курс, 2 студенти.

На першому курсі є по одному відміннику на ФІТ, ФКНК та ФРЕКС: Баранов, Костенко та Коваленко відповідно. За однакових значень обирається перший факультет у масиві faculties, тобто ФІТ. Це відповідає наведеному результату «ФІТ: 1».

Висновки

У лабораторній роботі використано структуру для збереження пов’язаних відомостей про студента. Масив структур дозволив опрацьовувати факультет, курс, групу, прізвище та оцінки як один запис. Реалізовано ручне й автоматичне заповнення, табличне виведення та меню окремих запитів.

Пошук студентів із незадовільними оцінками поєднав перевірку текстового поля з підрахунком елементів масиву оцінок. У контрольному прикладі на ФІТ знайдено шість записів із двома або більше двійками. Після їх вилучення кількість записів зменшилася з 25 до 19, що підтверджено повторним виведенням таблиці.

Під час видалення важливо було зберегти правильний порядок обходу: після зсуву на поточному місці з’являється наступний студент, якого також потрібно перевірити. Накопичення статистики до вилучення дозволило зберегти відомості про курси вже відсутніх у масиві студентів.

Підрахунок відмінників показав по одному студентові першого курсу з усіма оцінками «5» на кожному факультеті. У наведеній реалізації за рівних максимумів обирається ФІТ як перший факультет. Аналогічно для вилучень по два студенти на першому й четвертому курсах виведено перший курс.

Робота закріпила обробку масивів структур, пошук за кількома ознаками, вилучення зі зсувом і використання допоміжних лічильників. Ручна перевірка таблиць допомогла оцінити не лише кількість знайдених записів, а й поведінку програми у випадку рівних результатів запитів.
