Тема та мета

Тема: Текстові та бінарні файли.

Мета: Вивчити особливості використання текстових і бінарних файлів. Навчитися застосовувати текстові та бінарні файли в програмуванні.

Умова завдань

Завдання 1

Створити текстовий файл, кожний рядок якого містить різні слова. Знайти найкоротше слово в кожному рядку файлу. Переписати знайдені слова в новий текстовий файл, порахувавши їх кількість. Записати останнім рядком нового файлу кількість слів. Передбачити створення файлу з клавіатури, виведення його вмісту та меню операцій. Обробку рядків виконувати в окремій функції без STL, класу string та ітераторів.

Завдання 2

Створити масив структур із полями: факультет, курс, група, прізвище студента та екзаменаційні оцінки. Записати масив до бінарного файлу. Реалізувати читання й табличне виведення, додавання нових записів, заміну вибраного запису даними з клавіатури та видалення запису за вибором користувача.

Знайти й вилучити студентів факультету ФІТ, які мають дві та більше двійок за сесію; визначити факультет із найбільшою кількістю відмінників першого курсу та курс, з якого вилучено найбільше студентів. Дані для запитів читати з бінарного файлу, результати записати до нових бінарних файлів і вивести у вигляді таблиць. Використати структуру з LAB10 та організувати меню запитів.

Аналіз завдань

Завдання 1

Функція createTextFile() вводить кількість рядків і зберігає їх у text.txt. Функція outputTextFile() відкриває заданий файл у режимі читання та виводить рядки, отримані за допомогою fgets.

У findShortestWord() позиція i рухається від початку до кінця рядка. Функція strspn пропускає роздільники, а strcspn визначає довжину наступного слова. Якщо слово коротше за знайдене раніше, воно копіюється в окремий символьний масив. За однакової довжини зберігається перше слово.

Функція processTextFile() читає початковий файл, обробляє кожний рядок і записує непорожні знайдені слова в result.txt. Лічильник wordCount збільшується лише після знаходження слова. Наприкінці файлу записується його значення. Порожні рядки та рядки лише з роздільниками не додають слів до результату.

Використано масиви по 256 символів: до 255 символів тексту та завершальний нуль. Роздільники: пробіл, кома, крапка, крапка з комою, двокрапка, знак оклику, знак питання, табуляція та кінець рядка. Введення і файли розраховані на Windows-1251.

Завдання 2

З LAB10 використано структуру studentData: факультет, курс, група, прізвище і шість оцінок. Масив містить до 40 студентів. Дозволені факультети — ФІТ, ФКНК, ФРЕКС; курси — 1–4; оцінки — 2–5. Дані вводяться вручну. Група містить до 9 символів, прізвище — до 14.

writeStudents() записує структури за допомогою fwrite: режим wb створює або перезаписує файл, ab додає записи в кінець. readStudents() читає масив із students.bin. Для заміни або видалення програма читає файл у масив і після зміни записує його знову. При видаленні наступні елементи зсуваються на одну позицію вліво.

Під час відрахування підраховуються двійки кожного студента. Записи ФІТ із двома або більше двійками додаються до deleted.bin, а решта перезаписуються в students.bin. Звичайне видалення через пункт 5 меню не вважається відрахуванням за неуспішність. Створення нового набору студентів очищає файл відрахованих.

Відмінник першого курсу має course == 1 та всі шість оцінок, рівні 5. Кількості відмінників за трьома факультетами зберігаються в faculties.bin. Кількості відрахованих за чотирма курсами визначаються читанням deleted.bin і зберігаються в courses.bin. Функція outputCounts() повторно читає результати з файлу та позначає всі однакові ненульові максимуми.

Операції з файлами виконуються у відповідних функціях із закриттям відкритих файлів. Функція main() лише викликає виведення умови та меню. У реалізації немає STL, std::string, нескінченних циклів або примусового виходу з циклів; break використано тільки в switch.

/// <summary>
/// Вводить ціле число в заданих межах
/// </summary>
/// <param name="minValue">Найменше допустиме число</param>
/// <param name="maxValue">Найбільше допустиме число</param>
int inputNumber(int minValue, int maxValue)
{
	int value = minValue; // Введене число
	bool correctInput = false; // Ознака правильного введення
	do
	{
		cin >> value;
		correctInput = !cin.fail() && value >= minValue && value <= maxValue;
		if (!correctInput && !cin.eof())
		{
			cin.clear();
			cin.ignore(10000, '\n');
			cout << "Введіть число від " << minValue << " до " << maxValue << ": ";
		}
	} while (!correctInput && !cin.eof());
	return value;
}

/// <summary>
/// Створює текстовий файл із рядків, введених із клавіатури
/// </summary>
void createTextFile()
{
	FILE* file = fopen("text.txt", "w"); // Початковий файл
	if (file != NULL)
	{
		cout << "Введіть кількість рядків (0-100): ";
		int lineCount = inputNumber(0, 100); // Кількість рядків
		char line[maxStringLength]; // Поточний рядок
		cin.ignore(10000, '\n');
		cout << "Вводьте рядки до 255 символів." << endl;
		for (int i = 0; i < lineCount && !cin.eof(); i++)
		{
			cout << "Рядок " << i + 1 << ": ";
			cin.getline(line, maxStringLength);
			while (cin.fail() && !cin.eof())
			{
				cin.clear();
				cin.ignore(10000, '\n');
				cout << "Рядок задовгий. Введіть ще раз: ";
				cin.getline(line, maxStringLength);
			}
			if (!cin.eof()) fprintf(file, "%s\n", line);
		}
		if (fclose(file) != 0) cout << "Помилка запису файлу." << endl;
	}
	else cout << "Не вдалося створити файл." << endl;
}

/// <summary>
/// Виводить вміст текстового файлу на екран
/// </summary>
/// <param name="fileName">Назва файлу</param>
void outputTextFile(const char fileName[])
{
	FILE* file = fopen(fileName, "r"); // Файл для читання
	char line[maxStringLength]; // Рядок файлу
	if (file != NULL)
	{
		cout << "Вміст " << fileName << ":" << endl;
		while (fgets(line, maxStringLength, file) != NULL)
		{
			cout << line;
		}
		fclose(file);
		cout << endl;
	}
	else cout << "Файл не знайдено." << endl;
}

/// <summary>
/// Знаходить перше найкоротше слово рядка
/// </summary>
/// <param name="line">Початковий рядок</param>
/// <param name="shortestWord">Знайдене слово або порожній рядок</param>
void findShortestWord(const char line[], char shortestWord[])
{
	size_t i = 0; // Поточна позиція в рядку
	size_t minLength = maxStringLength; // Найменша довжина слова
	shortestWord[0] = '\0';
	while (line[i] != '\0')
	{
		i += strspn(line + i, " ,.;:!?\t\n\r");
		size_t wordLength = strcspn(line + i, " ,.;:!?\t\n\r"); // Довжина слова
		if (wordLength > 0 && wordLength < minLength)
		{
			minLength = wordLength;
			strncpy(shortestWord, line + i, wordLength);
			shortestWord[wordLength] = '\0';
		}
		i += wordLength;
	}
}

/// <summary>
/// Записує найкоротші слова та їх кількість у новий текстовий файл
/// </summary>
void processTextFile()
{
	FILE* input = fopen("text.txt", "r"); // Початковий файл
	if (input != NULL)
	{
		FILE* output = fopen("result.txt", "w"); // Файл результатів
		if (output != NULL)
		{
			char line[maxStringLength]; // Рядок початкового файлу
			char shortestWord[maxStringLength]; // Найкоротше слово рядка
			int wordCount = 0; // Кількість знайдених слів
			while (fgets(line, maxStringLength, input) != NULL)
			{
				findShortestWord(line, shortestWord);
				if (shortestWord[0] != '\0')
				{
					fprintf(output, "%s\n", shortestWord);
					wordCount++;
				}
			}
			fprintf(output, "%d\n", wordCount);
			if (fclose(output) == 0) outputTextFile("result.txt");
			else cout << "Помилка запису результату." << endl;
		}
		else cout << "Не вдалося створити файл результатів." << endl;
		fclose(input);
	}
	else cout << "Спочатку створіть текстовий файл." << endl;
}

/// Викликає операції з файлами відповідно до вибору користувача

{
	int choice = 1; // Обраний пункт меню
	while (choice != 0 && !cin.eof())
	{
		cout << "1. Створити файл" << endl
			<< "2. Вивести початковий файл" << endl
			<< "3. Знайти найкоротші слова та записати результат" << endl
			<< "4. Вивести файл результатів" << endl
			<< "0. Вихід" << endl;
		cout << "Оберіть пункт меню: ";
		choice = inputNumber(0, 4);
		if (!cin.eof())
		{
			switch (choice)
			{
			case 1: createTextFile(); break;
			case 2: outputTextFile("text.txt"); break;
			case 3: processTextFile(); break;
			case 4: outputTextFile("result.txt"); break;
			}
		}
	}
}

/// <summary>
/// Записує масив структур у файл або дописує його в кінець файлу
/// </summary>
/// <param name="fileName">Назва файлу</param>
/// <param name="students">Масив студентів</param>
/// <param name="studentCount">Кількість записів</param>
/// <param name="mode">wb - перезапис, ab - доповнення</param>
bool writeStudents(const char fileName[], const studentData students[], int studentCount, const char mode[])
{
	FILE* file = fopen(fileName, mode); // Файл для запису
	bool success = false; // Результат запису
	if (file != NULL)
	{
		success = fwrite(students, sizeof(studentData), studentCount, file) == (size_t)studentCount;
		if (fclose(file) != 0) success = false;
	}
	if (!success) cout << "Помилка запису файлу " << fileName << endl;
	return success;
}

/// <summary>
/// Зчитує масив студентів із файлу
/// </summary>
/// <param name="students">Масив для прочитаних записів</param>
/// <returns>Кількість студентів або -1, якщо файл не вдалося прочитати</returns>
int readStudents(studentData students[])
{
	FILE* file = fopen("students.bin", "rb"); // Початковий бінарний файл
	int studentCount = -1; // Кількість прочитаних записів
	if (file != NULL)
	{
		studentCount = (int)fread(students, sizeof(studentData), maxStudentNumber, file);
		if (ferror(file) || fgetc(file) != EOF) studentCount = -1;
		fclose(file);
	}
	if (studentCount == -1) cout << "Не вдалося прочитати файл студентів." << endl;
	return studentCount;
}

/// <summary>
/// Виводить масив студентів у вигляді таблиці
/// </summary>
/// <param name="students">Масив даних студентів</param>
/// <param name="studentCount">Кількість студентів</param>
void studentsDataTableOutput(const studentData students[], int studentCount)
{
	cout << "============================================================================" << endl;
	cout << setw(4) << "№" << setw(12) << "Факультет" << setw(7) << "Курс"
		<< setw(12) << "Група" << setw(17) << "Прізвище" << "   Оцінки" << endl;
	for (int i = 0; i < studentCount; i++)
	{
		cout << setw(4) << i + 1 << setw(12) << students[i].faculty
			<< setw(7) << students[i].course << setw(12) << students[i].group
			<< setw(17) << students[i].surname << "   ";
		for (int j = 0; j < maxGradeNumber; j++)
		{
			cout << students[i].grade[j] << " ";
		}
		cout << endl;
	}
	if (studentCount == 0) cout << "Записів немає." << endl;
}

/// <summary>
/// Створює масив студентів і записує його в новий бінарний файл
/// </summary>
void createStudentsFile()
{
	studentData students[maxStudentNumber] = {}; // Масив студентів
	cout << "Введіть кількість студентів (0-40): ";

	for (int i = 0; i < studentCount && !cin.eof(); i++)
	{
		cout << "Студент " << i + 1 << endl;
		inputStudent(students[i]);
	}
	if (!cin.eof() && writeStudents("students.bin", students, studentCount, "wb"))
	{
		// Для нового набору даних очищаємо список відрахованих.
		writeStudents("deleted.bin", students, 0, "wb");
		studentsDataTableOutput(students, studentCount);
	}
}

/// <summary>
/// Зчитує студентів із бінарного файлу та виводить таблицю
/// </summary>
void outputStudentsFile()
{
	studentData students[maxStudentNumber]; // Прочитані записи
	int studentCount = readStudents(students); // Кількість записів
	if (studentCount >= 0) studentsDataTableOutput(students, studentCount);
}

/// <summary>
/// Дописує нового студента в кінець бінарного файлу
/// </summary>
void addStudent()
{
	studentData students[maxStudentNumber]; // Масив для визначення кількості студентів
	int studentCount = readStudents(students); // Поточна кількість записів
	if (studentCount >= 0 && studentCount < maxStudentNumber)
	{
		studentData student; // Новий студент
		inputStudent(student);
		if (!cin.eof()) writeStudents("students.bin", &student, 1, "ab");
	}
	else if (studentCount == maxStudentNumber) cout << "У файлі вже 40 студентів." << endl;
}

/// <summary>
/// Замінює або видаляє вибраний запис у бінарному файлі
/// </summary>
/// <param name="replace">true - замінити запис, false - видалити</param>
void changeStudent(bool replace)
{
	studentData students[maxStudentNumber]; // Записи початкового файлу
	int studentCount = readStudents(students); // Кількість студентів
	if (studentCount > 0)
	{
		studentsDataTableOutput(students, studentCount);
		cout << "Введіть номер запису: ";
		int index = inputNumber(1, studentCount) - 1; // Індекс вибраного запису
		if (!cin.eof())
		{
			if (replace) inputStudent(students[index]);
			else
			{
				for (int i = index; i < studentCount - 1; i++) students[i] = students[i + 1];
				studentCount--;
			}
			if (!cin.eof()) writeStudents("students.bin", students, studentCount, "wb");
		}
	}
	else if (studentCount == 0) cout << "Файл порожній." << endl;
}

/// <summary>
/// Вилучає студентів ФІТ із двома або більше двійками та зберігає їх в окремому файлі
/// </summary>
void deleteBadGradeStudents()
{
	studentData students[maxStudentNumber]; // Початкові записи
	studentData deletedStudents[maxStudentNumber]; // Відраховані студенти
	int studentCount = readStudents(students); // Кількість початкових записів
	int deletedCount = 0; // Кількість відрахованих студентів
	int remainingCount = 0; // Кількість студентів, які залишилися
	if (studentCount >= 0)
	{
		for (int i = 0; i < studentCount; i++)
		{
			int badGrades = 0; // Кількість двійок студента
			for (int j = 0; j < maxGradeNumber; j++)
			{
				if (students[i].grade[j] == 2) badGrades++;
			}
			if (strcmp(students[i].faculty, "ФІТ") == 0 && badGrades >= 2)
			{
				deletedStudents[deletedCount++] = students[i];
			}
			else students[remainingCount++] = students[i];
		}
		if (writeStudents("deleted.bin", deletedStudents, deletedCount, "ab")
			&& writeStudents("students.bin", students, remainingCount, "wb"))
		{
			cout << "Відраховані студенти:" << endl;
			studentsDataTableOutput(deletedStudents, deletedCount);
		}
	}
}

/// <summary>
/// Записує результати підрахунку в бінарний файл
/// </summary>
/// <param name="fileName">Назва файлу результатів</param>
/// <param name="counts">Масив кількостей</param>
/// <param name="count">Розмір масиву</param>
bool writeCounts(const char fileName[], const int counts[], int count)
{
	FILE* file = fopen(fileName, "wb"); // Файл результатів
	bool success = false; // Ознака успішного запису
	if (file != NULL)
	{
		success = fwrite(counts, sizeof(int), count, file) == (size_t)count;
		if (fclose(file) != 0) success = false;
	}
	if (!success) cout << "Не вдалося записати результат." << endl;
	return success;
}

/// <summary>
/// Зчитує результати з файлу та виводить таблицю, позначаючи найбільші значення
/// </summary>
/// <param name="fileName">Назва файлу результатів</param>
/// <param name="names">Назви факультетів або курсів</param>
/// <param name="count">Кількість рядків таблиці, не більше чотирьох</param>
void outputCounts(const char fileName[], const char names[][10], int count)
{
	FILE* file = fopen(fileName, "rb"); // Файл для читання
	int counts[4] = { 0 }; // Прочитані кількості
	int maximum = 0; // Найбільша кількість
	if (file != NULL)
	{
		if (fread(counts, sizeof(int), count, file) == (size_t)count)
		{
			for (int i = 0; i < count; i++)
			{
				if (counts[i] > maximum) maximum = counts[i];
			}
			cout << setw(12) << "Назва" << setw(12) << "Кількість" << endl;
			for (int i = 0; i < count; i++)
			{
				cout << setw(12) << names[i] << setw(12) << counts[i];
				if (maximum > 0 && counts[i] == maximum) cout << " - найбільше";
				cout << endl;
			}
			if (maximum == 0) cout << "Студентів за цим запитом немає." << endl;
		}
		else cout << "Помилка читання результату." << endl;
		fclose(file);
	}
	else cout << "Файл результатів не знайдено." << endl;
}

/// <summary>

void findFacultyWithMostTopStudents()
{
	studentData students[maxStudentNumber]; // Студенти з файлу

	int counts[3] = { 0 }; // Кількість відмінників на кожному факультеті
	if (studentCount >= 0)
	{
		for (int i = 0; i < studentCount; i++)
		{
			bool topStudent = students[i].course == 1; // Ознака відмінника першого курсу
			for (int j = 0; j < maxGradeNumber; j++)
			{
				if (students[i].grade[j] != 5) topStudent = false;
			}
			if (topStudent)
			{
				for (int j = 0; j < 3; j++)
				{
					if (strcmp(students[i].faculty, faculties[j]) == 0) counts[j]++;
				}
			}
		}
		if (writeCounts("faculties.bin", counts, 3))
		{
			cout << "Відмінники першого курсу за факультетами:" << endl;

		}
	}
}

/// <summary>
/// Зчитує відрахованих студентів і визначає курси з найбільшою їх кількістю
/// </summary>
void findCourseWithMostDeletedStudents()
{
	FILE* file = fopen("deleted.bin", "rb"); // Файл відрахованих студентів
	studentData student; // Поточний запис
	int counts[4] = { 0 }; // Кількість відрахованих за курсами
	const char courses[][10] = { "1", "2", "3", "4" }; // Назви курсів
	if (file != NULL)
	{
		while (fread(&student, sizeof(studentData), 1, file) == 1)
		{
			if (student.course >= 1 && student.course <= 4) counts[student.course - 1]++;
		}
		fclose(file);
		if (writeCounts("courses.bin", counts, 4))
		{
			cout << "Відраховані студенти за курсами:" << endl;
			outputCounts("courses.bin", courses, 4);
		}
	}
	else cout << "Спочатку створіть файл студентів." << endl;
}

Перевірка результатів

Завдання 1

Для перевірки введено п’ять рядків: «Програмування файл код», «Ми вивчаємо C++», «текст і дані», порожній рядок і «кіт пес». Найкоротшими словами є «код», «Ми», «і» та «кіт». У рядку «кіт пес» обидва слова мають однакову довжину, тому вибрано перше. Порожній рядок не додає слова до результату.

Файл result.txt містить чотири знайдені слова, а останнім рядком записано число 4. Результат збігається з ручним підрахунком. Додатково перевірено порожній файл, рядки лише з роздільниками, українські літери, введення рядка довжиною 255 символів і повторне введення після перевищення цієї межі.

Завдання 2

У контрольному масиві шість студентів: Іванов — ФІТ, 1-й курс, усі оцінки 5; Шевченко — ФКНК, 1-й курс, усі оцінки 5; Петров — ФІТ, 2-й курс, оцінки 2 2 3 4 5 5; Коваленко — ФІТ, 3-й курс, оцінки 2 3 2 4 5 5; Баранов — ФКНК, 2-й курс, усі оцінки 2; Костенко — ФІТ, 4-й курс, оцінки 2 3 3 4 4 5.

Програма вилучила Петрова і Коваленка: обидва навчаються на ФІТ та мають по дві двійки. У students.bin залишилося чотири записи. Баранова не вилучено, оскільки він навчається на іншому факультеті; Костенка не вилучено, оскільки він має лише одну двійку.

Ручний підрахунок відмінників першого курсу дає: ФІТ — 1, ФКНК — 1, ФРЕКС — 0. Програма позначила ФІТ і ФКНК як факультети з найбільшою кількістю відмінників. Кількість відрахованих за курсами: 1-й — 0, 2-й — 1, 3-й — 1, 4-й — 0. Другий і третій курси правильно позначено як максимальні.

Окремо перевірено додавання Ткаченка: кількість записів збільшилася з чотирьох до п’яти. Після заміни п’ятого запису змінилися курс та оцінки. Видалення цього запису повернуло кількість студентів до чотирьох. Повторний запит відрахування після перезапуску не додав повторних записів до deleted.bin. Також перевірено порожній файл, межу 40 студентів, нечислове введення, шість оцінок одним рядком, повідомлення про відсутній файл і завершення після кінця потоку введення.

Висновки

У лабораторній роботі реалізовано дві програми для обробки текстових і бінарних файлів. Використано функції відкриття, читання, запису та закриття файлів із бібліотеки stdio.h. Меню дозволяє виконувати окремі операції повторно та в довільному порядку.
