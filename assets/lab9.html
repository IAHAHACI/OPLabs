Тема та мета

Тема: Символьні рядки та масиви рядків.

Мета: Опанувати обробку символьних масивів, виділення слів, аналіз цифрових символів і перетворення рядка. Реалізувати послідовне перетворення слова з використанням словника.

Умова завдань

Завдання 1

Увести рядок зі словами, розділеними пропусками, комами та крапками. Передбачити меню для визначення кількості слів і найдовшого слова, обчислення суми цифр у словах, що складаються лише з цифр, та видалення однолітерних слів і зайвих роздільників. Вивести результати обраних дій.

Завдання 2

Увести початкове й кінцеве слова та словник як масив рядків. Перетворити одне слово в інше, змінюючи за один крок одну літеру. Використовувати слова словника та передбачити додавання потрібного слова, якщо продовження не знайдено. Вивести ланцюжок або повідомлення про неможливість перетворення.

Аналіз завдань

Завдання 1

Рядок розглядається як послідовність слів і роздільників. Функція strspn пропускає пропуски, коми та крапки, а strcspn визначає довжину наступного слова. За кожним виділеним словом збільшується лічильник; для найдовшого слова запам’ятовується найбільша довжина.

Для числового слова спочатку перевіряються всі символи за допомогою isdigit. До суми додаються значення його окремих цифр. Перетворення записується в інший масив: слова довжини один пропускаються, а між збереженими словами формується один пропуск із допустимим розділовим знаком.

Завдання 2

Функція compareWords перевіряє однакову довжину та рівно одну відмінну позицію. Послідовний перегляд словника вибирає перше придатне невикористане слово. Масив ознак usedWordFlags запобігає повторному використанню тих самих записів словника.

Якщо поточне слово відрізняється від кінцевого рівно на одну літеру, виконується завершальний перехід. За відсутності продовження можна додати нове слово, яке задовольняє цю умову відносно поточного. Наведений послідовний алгоритм залежить від порядку словника та не виконує пошуку найкоротшого ланцюжка.

/// <summary>
/// Функція для визначення кількості слів у рядку
/// </summary>
/// <param name="initialString">Початковий рядок символів</param>
/// <returns>Кількість слів у рядку</returns>
int findNumberOfWords(char* initialString)
{
	size_t wordLength; // Довжина поточного слова
	int numberOfWords = 0; // Кількість знайдених слів
	size_t startOfString; // Кількість розділових символів перед словом
	size_t i = 0; // Поточна позиція в рядку

	while (i < strlen(initialString))
	{
		startOfString = strspn(initialString + i, ", .");
		i += startOfString;

		if (initialString[i] == '\0')
		{
			break;
		}

		wordLength = strcspn(initialString + i, ", .");
		numberOfWords++;
		i += wordLength;
	}

	return numberOfWords;
}

/// <summary>
/// Функція для пошуку найдовшого слова у початковому рядку
/// </summary>
/// <param name="initialString">Початковий рядок символів</param>
/// <param name="longestWord">Масив для збереження найдовшого слова</param>
void findLongestWord(char* initialString, char* longestWord)
{
	size_t currentWordLength = 0; // Довжина поточного слова
	size_t maxWordLength = 0; // Максимальна довжина слова
	size_t stringSeparatorNumber; // Кількість розділових символів
	size_t longestWordStartPosition = 0; // Початкова позиція найдовшого слова
	size_t i = 0; // Поточна позиція в рядку

	while (i < strlen(initialString))
	{
		stringSeparatorNumber = strspn(initialString + i, ", .");
		i += stringSeparatorNumber;

		if (initialString[i] == '\0')
		{
			break;
		}

		currentWordLength = strcspn(initialString + i, ", .");

		if (currentWordLength > maxWordLength)
		{
			longestWordStartPosition = i;
			maxWordLength = currentWordLength;
		}

		i += currentWordLength;
	}

	for (size_t i = 0; i < maxWordLength; i++)
	{
		longestWord[i] = initialString[longestWordStartPosition + i];
	}

	longestWord[maxWordLength] = '\0';
}

/// <summary>
/// Функція для пошуку слів, що складаються лише з цифр,
/// та обчислення суми всіх цифр таких слів
/// </summary>
/// <param name="initialString">Початковий рядок символів</param>
/// <returns>Сума цифр усіх числових слів</returns>
int findDigitWordSum(char* initialString)
{
	int sum = 0; // Загальна сума цифр
	size_t currentWordLength = 0; // Довжина поточного слова
	size_t stringSeparatorNumber; // Кількість розділових символів
	size_t i = 0; // Поточна позиція в рядку
	bool wordIsDigit = true; // Ознака того, що слово складається лише з цифр

	while (i < strlen(initialString))
	{
		stringSeparatorNumber = strspn(initialString + i, ", .");
		i += stringSeparatorNumber;

		if (initialString[i] == '\0')
		{
			break;
		}

		currentWordLength = strcspn(initialString + i, ", .");

		wordIsDigit = true;

		for (size_t j = 0; j < currentWordLength; j++)
		{
			if (!isdigit(initialString[i + j]))
			{
				wordIsDigit = false;
				break;
			}
		}

		if (wordIsDigit)
		{
			for (size_t j = 0; j < currentWordLength; j++)
			{
				sum += initialString[i + j] - '0';
			}
		}

		i += currentWordLength;
	}

	return sum;
}

/// <summary>
/// Функція для видалення однолітерних слів та зайвих
/// пропусків, ком і крапок із початкового рядка
/// </summary>
/// <param name="initialString">Початковий рядок символів</param>
/// <param name="transformedString">Масив для збереження перетвореного рядка</param>
void transformInitialString(char* initialString, char* transformedString)
{
	size_t transformedStringIndex = 0; // Позиція запису в перетвореному рядку
	size_t stringSeparatorNumber; // Кількість розділових символів
	size_t currentWordLength = 0; // Довжина поточного слова
	size_t i = 0; // Поточна позиція в початковому рядку
	bool hasComma = false; // Ознака наявності коми
	bool hasDot = false; // Ознака наявності крапки

	while (i < strlen(initialString))
	{
		stringSeparatorNumber = strspn(initialString + i, ", .");
		size_t separatorStartPosition = i; // Початок послідовності роздільників
		i += stringSeparatorNumber;

		if (initialString[i] == '\0')
		{
			break;
		}

		currentWordLength = strcspn(initialString + i, ", .");

		for (size_t j = separatorStartPosition; j < i; j++)
		{
			if (initialString[j] == ',')
			{
				hasComma = true;
			}
			else if (initialString[j] == '.')
			{
				hasDot = true;
			}
		}

		if (currentWordLength == 1)
		{
			i += currentWordLength;
			continue;
		}

		if (transformedStringIndex != 0)
		{
			if (hasDot)
			{
				transformedString[transformedStringIndex] = '.';
				transformedStringIndex++;
			}
			else if (hasComma)
			{
				transformedString[transformedStringIndex] = ',';
				transformedStringIndex++;
			}

			transformedString[transformedStringIndex] = ' ';
			transformedStringIndex++;
		}

		hasComma = false;
		hasDot = false;

		for (size_t j = 0; j < currentWordLength; j++)
		{
			transformedString[transformedStringIndex] = initialString[i + j];
			transformedStringIndex++;
		}

		i += currentWordLength;
	}

	transformedString[transformedStringIndex] = '\0';
}

/// <summary>
/// Функція для введення початкового та кінцевого слів,
/// кількості слів у словнику та його заповнення
/// </summary>
/// <param name="n">Кількість слів у словнику</param>
/// <param name="firstWord">Початкове слово</param>
/// <param name="secondWord">Кінцеве слово</param>
/// <param name="wordVocabulary">Масив слів словника</param>
/// <param name="transformationPossible">
/// Ознака можливості виконання перетворення
/// </param>
void input(int& n, char* firstWord, char* secondWord,
	char wordVocabulary[][10], bool& transformationPossible)
{
	cout << "Введіть кількість слів у словнику (до 10 слів): ";
	cin >> n;

	while (n < 1 || n > maxVocabularySize)
	{
		cout << "Введіть коректне значення: ";
		cin >> n;
	}

	cout << "Введіть початкове слово: ";
	cin >> firstWord;

	cout << "Введіть кінцеве слово: ";
	cin >> secondWord;

	if (strlen(firstWord) != strlen(secondWord))
	{
		cout << "Слова різної довжини неможливо перетворити одне в одне."
			<< endl;
		transformationPossible = false;
		return;
	}

	if (strcmp(firstWord, secondWord) == 0)
	{
		cout << firstWord << endl;
		transformationPossible = false;
		return;
	}

	cout << "Введіть словник слів: " << endl;

	for (int i = 0; i < n; i++)
	{
		cin >> wordVocabulary[i];
	}
}

/// <summary>
/// Функція для перевірки відмінності між двома словами
/// рівно на одну літеру
/// </summary>
/// <param name="word">Перше слово для порівняння</param>
/// <param name="wordVocabulary">Друге слово для порівняння</param>
/// <returns>
/// true, якщо слова відрізняються рівно на одну літеру,
/// інакше false
/// </returns>
bool compareWords(char* word, char* wordVocabulary)
{
	if (strlen(word) != strlen(wordVocabulary))
	{
		return false;
	}

	int diferenceBetweenWords = 0; // Кількість відмінних літер

	for (int i = 0; i < strlen(word); i++)
	{
		if (word[i] != wordVocabulary[i])
		{
			diferenceBetweenWords++;
		}
	}

	if (diferenceBetweenWords == 1)
	{
		return true;
	}

	return false;
}

/// <summary>
/// Функція для заміни відмінних літер поточного слова
/// відповідними літерами іншого слова
/// </summary>
/// <param name="word">Поточне слово, яке змінюється</param>
/// <param name="wordVocabulary">Слово, за яким виконується заміна</param>
void changeWord(char* word, char* wordVocabulary)
{
	for (int i = 0; i < strlen(word); i++)
	{
		if (word[i] != wordVocabulary[i])
		{
			word[i] = wordVocabulary[i];
		}
	}
}

/// <summary>
/// Функція для додавання нового слова до словника,
/// якщо воно відрізняється від поточного рівно на одну літеру
/// </summary>
/// <param name="wordVocabulary">Масив слів словника</param>
/// <param name="n">Поточна кількість слів у словнику</param>
/// <param name="firstWord">Поточне слово для порівняння</param>
/// <returns>
/// true, якщо слово додано до словника,
/// інакше false
/// </returns>
bool addWordToVocabulary(char wordVocabulary[][10], int& n, char* firstWord)
{
	if (n == maxVocabularySize)
	{
		cout << "Неможливо додати нове слово, словник заповнений!" << endl;
		return false;
	}

	char newWord[10]; // Нове слово для додавання до словника

	cout << "Введіть нове слово: ";
	cin >> newWord;

	while (!compareWords(firstWord, newWord))
	{
		cout << "Нове слово повинно відрізнятися від поточного "
			<< "рівно на одну літеру!" << endl;
		cout << "Введіть нове слово: ";
		cin >> newWord;
	}

	strcpy(wordVocabulary[n], newWord);
	n++;

	return true;
}

/// <summary>
/// Функція для послідовного перетворення початкового слова
/// в кінцеве за допомогою слів зі словника
/// </summary>
/// <param name="transformationCompleted">
/// Ознака завершення перетворення
/// </param>
/// <param name="wordFound">
/// Ознака знаходження відповідного слова у словнику
/// </param>
/// <param name="n">Кількість слів у словнику</param>
/// <param name="firstWord">Поточне слово для перетворення</param>
/// <param name="secondWord">Кінцеве слово</param>
/// <param name="wordVocabulary">Масив слів словника</param>
/// <param name="usedWordFlags">
/// Масив ознак використаних слів словника
/// </param>
void transformWord(bool transformationCompleted, bool wordFound,
	int& n, char* firstWord, char* secondWord,
	char wordVocabulary[][10], bool* usedWordFlags)
{
	while (!transformationCompleted)
	{
		wordFound = false;

		for (int j = 0; j < n; j++)
		{
			if (compareWords(firstWord, wordVocabulary[j])
				&& !usedWordFlags[j])
			{
				wordFound = true;
				usedWordFlags[j] = true;

				changeWord(firstWord, wordVocabulary[j]);
				cout << " -> " << firstWord;

				if (compareWords(firstWord, secondWord))
				{
					changeWord(firstWord, secondWord);
					cout << " -> " << firstWord << endl;
					transformationCompleted = true;
				}

				break;
			}
		}

		if (!wordFound)
		{
			cout << endl;
			cout << "Не знайдено слова для продовження перетворення."
				<< endl;

			if (!addWordToVocabulary(wordVocabulary, n, firstWord))
			{
				cout << "Слово неможливо перетворити." << endl;
				break;
			}
		}
	}
}

/// <summary>
/// Головна функція програми для керування процесом
/// перетворення початкового слова в кінцеве
/// </summary>
/// <returns>Код завершення програми</returns>
int main()
{
	int n = 0; // Кількість слів у словнику
	char wordVocabulary[maxVocabularySize][10]; // Масив слів словника
	char firstWord[10]; // Початкове слово
	char secondWord[10]; // Кінцеве слово
	bool usedWordFlags[maxVocabularySize] = {}; // Ознаки використаних слів
	bool transformationCompleted = false; // Ознака завершення перетворення
	bool wordFound = false; // Ознака знаходження слова у словнику
	bool transformationPossible = true; // Ознака можливості перетворення

	identificationOutput();
	input(n, firstWord, secondWord, wordVocabulary, transformationPossible);

	if (!transformationPossible)
	{
		return 0;
	}

	cout << firstWord;

	if (compareWords(firstWord, secondWord))
	{
		changeWord(firstWord, secondWord);
		cout << " -> " << firstWord << endl;
		transformationCompleted = true;
	}

	transformWord(transformationCompleted, wordFound, n, firstWord,
		secondWord, wordVocabulary, usedWordFlags);

	return 0;
}

Перевірка результатів

Завдання 1

Для рядка «Програмування, 12282, а робота.» визначено чотири слова. Найдовше — «Програмування». Сума цифр числового слова 12282 дорівнює 1 + 2 + 2 + 8 + 2 = 15, що підтверджено WolframAlpha. Після видалення слова «а» отримано «Програмування, 12282, робота».

У додатковому тесті повторені однолітерні слова видалено, а результат має вигляд «програмування, робота».

Завдання 2

Для початкового слова hit, кінцевого cog і словника hot, dot, dog, lot, log отримано hit → hot → dot → dog → cog. У кожній парі сусідніх слів змінено рівно одну позицію; проміжні слова є у введеному словнику.

Висновки

У ході лабораторної роботи опрацьовано символьні масиви та стандартні функції обробки C-рядків. Закріплено визначення довжини, виділення слів за роздільниками, порівняння та копіювання символів. Меню команд дозволило перевірити різні операції над одним початковим рядком.

У першому завданні правильно визначено чотири слова контрольного рядка та знайдено найдовше слово «Програмування». Перевірка числового слова 12282 дала суму цифр 15. Це дозволило відрізнити додавання цифр від додавання числових значень цілих слів.

Перетворення рядка вилучило однолітерне слово та зайві роздільники, зберігши послідовність інших слів. Додатковий тест із кількома однолітерними словами показав роботу пропуску коротких фрагментів і формування роздільника між збереженими словами.

У другому завданні побудовано ланцюжок hit → hot → dot → dog → cog. Перевірка сусідніх пар підтвердила зміну рівно однієї літери на кожному кроці. Використання ознак уже обраних слів дозволило не повертатися до тих самих записів словника.

Робота закріпила послідовну обробку тексту, перевірку властивостей символів та побудову результату в окремому масиві. Під час аналізу перетворення слів враховано, що вибір першого придатного слова залежить від порядку словника та не гарантує найкоротшого шляху.
