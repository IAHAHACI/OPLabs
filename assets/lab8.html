Тема та мета

Тема: Динамічні масиви, вказівники та розріджені матриці.

Мета: Навчитися створювати динамічні матриці й подання COO, передавати дані через вказівники та викликати функції через вказівники на функції. Порівняти обчислення суми діагоналі, час виконання й обсяг пам’яті для двох подань.

Умова завдання

Завдання 1

Згенерувати матрицю заданих розмірів, у якій понад 60% елементів нульові. Побудувати координатне подання COO у вигляді трьох одновимірних масивів: значень ненульових елементів, індексів рядків та індексів стовпців. Вивести матрицю й масиви COO. Обчислити суму діагональних елементів за координатним і стандартним алгоритмами, порівняти час та обсяг пам’яті. Передбачити меню команд і звільнення виділеної пам’яті.

Аналіз завдань

Завдання 1

Матриця створюється динамічно за введеними додатними розмірами. Генерація повторюється, поки частка нульових елементів не перевищить 60%. Після цього два проходи визначають кількість ненульових елементів та заповнюють три масиви COO. Елементи зберігаються разом зі своїми координатами.

Для COO сума діагоналі визначається за рівністю індексів рядка і стовпця. Стандартний алгоритм у наведеній реалізації обходить усі елементи матриці та перевіряє i == j. Обидва алгоритми працюють з однією матрицею, тому мають дати однакову суму.

Обсяг даних звичайної матриці обчислюється як rows · columns · sizeof(int), а трьох масивів COO — як 3 · nnz · sizeof(int). У ці значення не входять службові витрати виділення пам’яті та масив вказівників на рядки. Для вимірювання часу кожне обчислення повторюється 1000 разів, після чого визначається середнє значення.

/// <summary>
/// Звільняє пам’ять, виділену для попередньої матриці.

/// <param name="sparseMatrix">Вказівник на матрицю</param>

void clearMatrixBeforeGeneration(int** sparseMatrix, int numberOfRows)
{
	if (sparseMatrix != NULL)
	{
		for (int i = numberOfRows - 1; i >= 0; i--)
		{
			delete[] * (sparseMatrix + i);
		}

		delete[] sparseMatrix;
	}
}

/// <summary>
/// Перевіряє, чи частка нульових елементів перевищує 60%.
/// </summary>
/// <param name="sparseMatrix">Матриця для перевірки</param>
/// <param name="numberOfRows">Кількість рядків</param>
/// <param name="numberOfColumns">Кількість стовпців</param>
/// <returns>true, якщо нулів понад 60%, інакше false</returns>
bool checkMatrixForSixtyPercentZeros(int** sparseMatrix, int numberOfRows, int numberOfColumns)
{
	int zerosCount = 0; // Кількість нульових елементів
	int numberOfElements = numberOfRows * numberOfColumns; // Загальна кількість елементів

	for (int i = 0; i < numberOfRows; i++)
	{
		for (int j = 0; j < numberOfColumns; j++)
		{
			if (*(*(sparseMatrix + i) + j) == 0)
			{
				zerosCount++;
			}
		}
	}

	return numberOfElements * 0.6 < zerosCount;
}

/// <summary>
/// Заповнює матрицю випадковими числами до виконання умови розрідженості.
/// </summary>
/// <param name="sparseMatrix">Матриця для заповнення</param>
/// <param name="numberOfRows">Кількість рядків</param>
/// <param name="numberOfColumns">Кількість стовпців</param>
void fillSparseMatrix(int** sparseMatrix, int numberOfRows, int numberOfColumns)
{
	do
	{
		for (int i = 0; i < numberOfRows; i++)
		{
			for (int j = 0; j < numberOfColumns; j++)
			{
				*(*(sparseMatrix + i) + j) = rand() % 15;

				if (*(*(sparseMatrix + i) + j) < 10)
				{
					*(*(sparseMatrix + i) + j) = 0;
				}
			}
		}
	} while (!checkMatrixForSixtyPercentZeros(sparseMatrix, numberOfRows, numberOfColumns));
}

/// <summary>
/// Створює три масиви COO для зберігання ненульових елементів.
/// </summary>
/// <param name="sparseMatrix">Початкова матриця</param>
/// <param name="numberOfRows">Кількість рядків</param>
/// <param name="numberOfColumns">Кількість стовпців</param>
/// <param name="matrixElementValues">Масив значень COO</param>
/// <param name="rowIndexes">Масив індексів рядків</param>
/// <param name="columnIndexes">Масив індексів стовпців</param>
/// <param name="nonZeroElements">Кількість ненульових елементів</param>
void coordinateMatrixCreate(int** sparseMatrix, int numberOfRows, int numberOfColumns,
	int*& matrixElementValues, int*& rowIndexes,
	int*& columnIndexes, int& nonZeroElements)
{
	delete[] matrixElementValues;
	delete[] rowIndexes;
	delete[] columnIndexes;

	nonZeroElements = 0;
	for (int i = 0; i < numberOfRows; i++)
	{
		for (int j = 0; j < numberOfColumns; j++)
		{
			if (*(*(sparseMatrix + i) + j) != 0)
			{
				nonZeroElements++;
			}
		}
	}

	matrixElementValues = new int[nonZeroElements];
	rowIndexes = new int[nonZeroElements];
	columnIndexes = new int[nonZeroElements];
	int index = 0; // Позиція запису у масивах COO

	for (int i = 0; i < numberOfRows; i++)
	{
		for (int j = 0; j < numberOfColumns; j++)
		{
			if (*(*(sparseMatrix + i) + j) != 0)
			{
				*(matrixElementValues + index) = *(*(sparseMatrix + i) + j);
				*(rowIndexes + index) = i;
				*(columnIndexes + index) = j;
				index++;
			}
		}
	}
}

/// <summary>
/// Обчислює суму діагоналі у форматі COO та середній час обчислення.
/// </summary>
/// <param name="matrixElementValues">Масив значень COO</param>
/// <param name="rowIndexes">Індекси рядків</param>
/// <param name="columnIndexes">Індекси стовпців</param>
/// <param name="nonZeroElements">Кількість ненульових елементів</param>
/// <param name="coordinateTime">Середній час виконання в секундах</param>
/// <returns>Сума діагональних елементів</returns>
int findSumOfDiagonalByCoordinate(int* matrixElementValues,
	int* rowIndexes, int* columnIndexes, int nonZeroElements, double& coordinateTime)
{
	int sum = 0; // Сума діагональних елементів

	clock_t start = clock(); // Початок вимірювання часу
	for (int indexForTime = 0; indexForTime < numberOfTimeMeasurements; indexForTime++)
	{
		sum = 0;

		for (int i = 0; i < nonZeroElements; i++)
		{
			if (*(rowIndexes + i) == *(columnIndexes + i))
			{
				sum += *(matrixElementValues + i);
			}
		}
	}
	clock_t end = clock(); // Кінець вимірювання часу

	coordinateTime = ((end - start) / (double)CLOCKS_PER_SEC) / numberOfTimeMeasurements;

	return sum;
}

/// <summary>
/// Обчислює суму діагоналі звичайним обходом матриці та вимірює час.
/// </summary>
/// <param name="sparseMatrix">Початкова матриця</param>
/// <param name="numberOfRows">Кількість рядків</param>
/// <param name="numberOfColumns">Кількість стовпців</param>
/// <param name="standartAlgorithmTime">Середній час виконання в секундах</param>
/// <returns>Сума діагональних елементів</returns>
int findSumOfDiagonalByStandartAlgorithm(int** sparseMatrix, int numberOfRows,
	int numberOfColumns, double& standartAlgorithmTime)
{
	int sum = 0; // Сума діагональних елементів

	clock_t start = clock(); // Початок вимірювання часу
	for (int indexForTime = 0; indexForTime < numberOfTimeMeasurements; indexForTime++)
	{
		sum = 0;

		for (int i = 0; i < numberOfRows; i++)
		{
			for (int j = 0; j < numberOfColumns; j++)
			{
				if (i == j)
				{
					sum += *(*(sparseMatrix + i) + j);
				}
			}
		}
	}
	clock_t end = clock(); // Кінець вимірювання часу

	standartAlgorithmTime = ((end - start) / (double)CLOCKS_PER_SEC) / numberOfTimeMeasurements;

	return sum;
}

/// <summary>
/// Звільняє пам’ять матриці та масивів COO.
/// </summary>
/// <param name="matrixElementValues">Масив значень COO</param>
/// <param name="rowIndexes">Масив індексів рядків</param>
/// <param name="columnIndexes">Масив індексів стовпців</param>
/// <param name="sparseMatrix">Початкова матриця</param>
/// <param name="numberOfRows">Кількість рядків</param>
void clearMemory(int* matrixElementValues, int* rowIndexes, int* columnIndexes,
	int** sparseMatrix, int numberOfRows)
{
	delete[] matrixElementValues;
	delete[] rowIndexes;
	delete[] columnIndexes;
	if (sparseMatrix != NULL)
	{
		for (int i = numberOfRows - 1; i >= 0; i--)
		{
			delete[] * (sparseMatrix + i);
		}
		delete[] sparseMatrix;
	}
}

Перевірка результатів

Завдання 1

Для матриці 3 × 5 у COO записано п’ять ненульових значень: 13, 11, 11, 11, 10. Лише елемент зі значенням 11 та координатами (2, 2) належить головній діагоналі. Обидва алгоритми й перевірка в Excel дають суму 11.

За sizeof(int) = 4 байти звичайні елементи матриці займають 3 · 5 · 4 = 60 байт. Три масиви COO займають 3 · 5 · 4 = 60 байт. Для цього невеликого прикладу обсяги однакові.

У тесті 1000 × 1000 наведено 4 000 000 байт для звичайного подання та 4 001 316 байт для COO. У цьому прикладі координатне подання трохи більше через збереження двох індексів для кожного ненульового значення. Час у наведеному запуску становить 0,000278 с для COO та 0,000473 с для стандартного обходу.

Висновки

У лабораторній роботі реалізовано створення динамічної матриці та її координатного подання. Закріплено виділення й звільнення пам’яті, доступ до елементів через вказівники та передавання масивів між функціями. Меню дозволило окремо виконувати генерацію, виведення, обчислення та порівняння.

Формат COO зберігає лише ненульові значення, але для кожного з них потребує також індексів рядка й стовпця. На прикладі матриці 3 × 5 побудовано п’ять координатних записів. Перевірка рівності координат виділила єдиний ненульовий діагональний елемент зі значенням 11, що збіглося зі стандартним обчисленням і результатом Excel.

Порівняння пам’яті показало, що сама наявність понад 60% нулів ще не гарантує економії для трьох масивів цілих чисел. Для малого прикладу обсяги даних однакові, а для наведеного великого прикладу COO трохи перевищує звичайне подання. За однакового розміру значення та індексів економія виникає, коли ненульових елементів менше третини від загальної кількості.

У великому тесті координатний обхід виконався швидше за стандартний повний обхід матриці. Вимірювання через повторні обчислення дозволило отримати ненульові значення часу. Для малого прикладу виведений нульовий час означає, що виміряна тривалість не була розрізнена використаним таймером, а не відсутність обчислень.

Робота закріпила вибір подання даних залежно від структури матриці та конкретного алгоритму. Отримані результати показали, що час і пам’ять слід аналізувати окремо, враховуючи кількість ненульових елементів, збереження індексів і спосіб обходу даних.
